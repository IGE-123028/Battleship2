⚓ Battleship 2.0

Uma abordagem moderna ao clássico jogo de combate naval, concebida para o cenário histórico do século XVII com padrões de engenharia de software atualizados.

Gameplay

🎯 Visão Geral do Projeto & Regras

Este projeto serve como modelo e referência para estudantes de engenharia e ciências da computação que estão a aprender Programação Orientada a Objetos (OOP) e Qualidade de Software. O sistema simula um ambiente tático de batalha naval no qual os jogadores devem posicionar estrategicamente a sua frota de navios e afundar a armada inimiga.

🎮 Regras do Jogo

O jogo é jogado numa grelha quadrada bidimensional (geralmente com uma dimensão de 10x10). O sistema de coordenadas cartesianas discretas é rigorosamente definido pela seguinte fórmula matemática:

$$(x, y) \in \{0, \dots, 9\} \times \{0, \dots, 9\}$$

Os impactos tiros vs. navios são calculados dinamicamente com base na interseção geométrica do vetor do disparo efetuado e a caixa delimitadora (bounding box) da embarcação afetada.

Padrões de Desenho (Design Patterns) Aplicados

  • Strategy Pattern: Empregue para gerir dinamicamente e permutar entre os diferentes níveis de dificuldade do oponente de Inteligência Artificial.
  • Observer Pattern: Utilizado na sincronização visual de eventos, notificando a interface utilizador sempre que uma embarcação sofre um impacto destrutivo.

🗺 Roteiro de Desenvolvimento (Roadmap)

O ciclo de evolução planeado para as próximas iterações do Battleship 2.0 engloba:

  • Implementação da grelha de tabuleiro base parametrizada.
  • Algoritmos de validação matemática do posicionamento dos navios.

🤖 Prompt Final de Comportamento para LLM

O comportamento e as decisões táticas do oponente de IA nas partidas avançadas do Battleship são instruídos pelo seguinte prompt operacional estruturado em formato estrito:

CORTEZA TACTICAL AI v2.0
SISTEMA OPERACIONAL ATIVO
Instruções de Missão
  • Minimizar contagem total de disparos até neutralização total da frota.
  • Estruturar resposta final estritamente em formato JSON legível.
  • Proibida a inserção de marcas markdown de código no corpo.
  • Fornecer exatamente 3 disparos por rodada.
Regras Táticas e Heurísticas
  • Ao registar impacto positivo, priorizar células cardinais adjacentes.
  • Evitar Halo envolvente de navios já neutralizados.
  • Aplicar sistema de rastreio de paridade rectangular.
  • Diagonais apenas viáveis contra o cruzador do tipo Galeão.

[TACTICAL] Salva 1: Tiros em D3 (Água), G4 (Água), F7 (Impacto - Fragata!).
[TACTICAL] Salva 2: Focando adjacências de F7 -> F8 (Impacto!), F9 (Água).
[SISTEMA] Fragata inimiga afundada. Registando área circundante como neutra.

🤝 Como Contribuir para o Projeto

As contribuições sustentam a comunidade de código aberto como um ecossistema valioso para aprender, inovar e programar colaborativamente:

  1. Faça um Fork deste repositório na sua conta GitHub.
  2. Crie um ramo local para a sua funcionalidade (git checkout -b feature/FuncionalidadeIncrivel).
  3. Submeta as suas alterações localmente (git commit -m 'Add: Alguma Funcionalidade Incrível').
  4. Faça um envio remoto para o ramo correspondente (git push origin feature/FuncionalidadeIncrivel).
  5. Submeta um Pull Request para revisão da equipa do projeto.
