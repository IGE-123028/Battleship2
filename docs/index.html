A modern take on the classic naval warfare game, designed for the XVII century setting with updated software engineering patterns.

Gameplay

🎯 Project Overview & Rules

This project serves as a template and reference for students learning Object-Oriented Programming (OOP) and Software Quality. It simulates a battleship tactical environment where players must strategically place ships and sink the enemy fleet.

🎮 The Rules

The game is played on a grid (typically 10x10). The coordinate system is mathematically defined as:

$$(x, y) \in \{0, \dots, 9\} \times \{0, \dots, 9\}$$

Hits are calculated dynamically based on the geometric intersection of the shot vector and the ship's bounding box.

Design Patterns Employed

  • Strategy Pattern: Leveraged to support dynamic hot-swapping between different AI tactical target-seeking levels.
  • Observer Pattern: Used to update the user interface immediately when a ship coordinates record damage.

Game Logic Flow

The flowchart below documents the main round-based state machine that governs a complete game loop in Battleship: 

graph TD
    A[Start Game] --> B{Place Ships}
    B --> C[Player Turn]
    C --> D[Target Coordinate]
    D --> E{Hit or Miss?}
    E -- Hit --> F[Check if Sunk]
    E -- Miss --> G[AI Turn]
    F --> G
    G --> C
